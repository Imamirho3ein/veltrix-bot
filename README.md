# ربات تلگرام VELTRIX STUDIO

ربات فروش، مشاوره و سفارش‌گیری خدمات طراحی سایت — کاملاً مستقل و بدون نیاز به
دیتابیس. محتوا داخل کد است و داده‌ها در فایل‌های JSON ذخیره می‌شوند.

ربات: [@VeltrixStudio_bot](https://t.me/VeltrixStudio_bot)

## امکانات

**فروش و کاتالوگ**

- منوی فارسی دکمه‌ای
- نمایش **همهٔ ۹ سرویس تعرفه** با قیمت قالب آماده و طرح اختصاصی، زمان تحویل و امکانات
- خدمات تکمیلی (سئو، محتوا، UI/UX، پشتیبانی، سرعت)
- 🧮 **ماشین‌حساب قیمت**: نوع سایت → نوع طراحی → حجم پروژه → گزینه‌ها → برآورد
  بازهٔ قیمت، و تبدیل مستقیم برآورد به سفارش
- 🖼 **نمونه‌کارها** با نتایج، خدمات و لینک مشاهده در سایت

**سفارش**

- فرم مرحله‌به‌مرحله: خدمت → پلن → نام → تلفن (یا ارسال مخاطب) → توضیحات →
  **پیوست بریف/لوگو (عکس یا فایل)** → بودجه → تأیید
- کد پیگیری یکتا `VT-YYMM-XXXX`
- «سفارش‌های من» با **نوار پیشرفت**، تاریخچهٔ وضعیت و امکان **لغو سفارش** تا قبل از شروع اجرا

**پشتیبانی دوطرفه**

- مشتری پیام/عکس/فایل می‌فرستد → برای همهٔ مدیران ارسال می‌شود
- مدیر با یک دکمه به همان مشتری پاسخ می‌دهد
- همهٔ تیکت‌ها در `data/tickets.json` ثبت می‌شوند

**پنل مدیریت**

- `/admin` با منوی دکمه‌ای و ثبت خودکار اولین مدیر
- اعلان فوری سفارش جدید + ارسال فایل بریف برای مدیران
- سفارش‌های جدید / همهٔ سفارش‌ها با **صفحه‌بندی**
- تغییر وضعیت (مشتری خودکار مطلع می‌شود)
- جستجو با کد پیگیری، نام، شمارهٔ تماس یا آیدی تلگرام
- **ثبت پرداخت**، **یادداشت داخلی**، **پیام مستقیم به مشتری**
- آمار کامل: امروز/هفته/مشتریان/پرداخت‌شده/درآمد/پرتقاضاترین خدمات
- 📤 **خروجی CSV** از همهٔ سفارش‌ها
- 📣 **پیام همگانی** به همهٔ مشتریان با تأیید
- ارسال پست به کانال و `/setchannel`

**زیرساخت**

- **ذخیرهٔ جلسه‌ها روی دیسک**: سفارش نیمه‌کاره بعد از ری‌استارت از بین نمی‌رود
- محافظت ساده در برابر پیام پشت‌سرهم (flood guard)
- پشتیبانی از پروکسی HTTP/SOCKS5

## راه‌اندازی

```bash
cd veltrix-bot
npm install
```

فایل `.env`:

```env
TELEGRAM_BOT_TOKEN="توکن ربات"
ADMIN_TELEGRAM_IDS="8917877282"
TELEGRAM_CHANNEL_ID="@VeeltrixStudio"
FORCE_CHANNEL_JOIN="true"
TELEGRAM_CHANNEL_URL="https://t.me/VeeltrixStudio"
TELEGRAM_SUPPORT_URL="https://t.me/ImAmirh3ein"
```

> کانال رسمی: [@VeeltrixStudio](https://t.me/VeeltrixStudio) — مالک/پشتیبانی:
> [@ImAmirh3ein](https://t.me/ImAmirh3ein) (شناسهٔ عددی `8917877282`).

> شناسهٔ خود را با `/myid` بگیرید. اگر `ADMIN_TELEGRAM_IDS` خالی باشد، **اولین
> کسی که `/admin` بزند** مدیر می‌شود؛ پس بلافاصله بعد از راه‌اندازی این کار را کنید.

### عضویت اجباری در کانال

با `FORCE_CHANNEL_JOIN="true"` (پیش‌فرض) کاربر باید قبل از دیدن خدمات در کانال
`@VeeltrixStudio` عضو شود:

- ربات عضویت را با `getChatMember` بررسی می‌کند و نتیجه را ۶۰ ثانیه کش می‌کند.
- تا وقتی کاربر عضو نشده، به‌جای منو و خدمات پیام «عضویت در کانال الزامی است» با
  دکمه‌های «📣 عضویت در کانال» و «✅ عضو شدم» می‌بیند.
- دکمهٔ «✅ عضو شدم» وضعیت را بدون کش دوباره بررسی می‌کند.
- مدیران ربات از این بررسی معاف‌اند.
- اگر تلگرام خطا بدهد (مثلاً ربات هنوز ادمین کانال نیست) ربات به‌صورت
  **fail-open** اجازهٔ استفاده می‌دهد تا مشتری قفل نشود.

> برای بررسی مطمئن عضویت، ربات باید در کانال **ادمین** باشد.

اجرا:

```bash
npm run dev     # توسعه با ری‌استارت خودکار
npm start       # اجرای عادی
```

خروجی موفق:

```
[bot] @VeltrixStudio_bot is up and running.
```

## ساختار

```
veltrix-bot/
├── src/
│   ├── index.ts            # راه‌اندازی، session روی دیسک، flood guard
│   ├── config.ts           # متغیرهای محیطی
│   ├── data.ts             # تعرفه‌ها، خدمات تکمیلی، نمونه‌کارها، FAQ
│   ├── store.ts            # سفارش‌ها، تیکت‌ها، مدیران، تنظیمات، CSV
│   ├── sessionStorage.ts   # ذخیرهٔ جلسه‌ها در data/sessions.json
│   ├── notify.ts           # اعلان مدیر/کانال/مشتری و ارسال بریف
│   ├── keyboards.ts        # دکمه‌ها
│   ├── session.ts          # وضعیت جلسه، فرم سفارش، ماشین‌حساب
│   ├── ui.ts               # متن‌ها، نوار پیشرفت، تاریخ شمسی
│   └── handlers/
│       ├── menu.ts         # منو، درباره، سوالات، تماس
│       ├── catalog.ts      # خدمات و تعرفه
│       ├── calculator.ts   # ماشین‌حساب قیمت
│       ├── portfolio.ts    # نمونه‌کارها
│       ├── order.ts        # فرم سفارش + پیوست بریف
│       ├── account.ts      # سفارش‌های من، لغو سفارش
│       ├── support.ts      # پشتیبانی دوطرفه
│       └── admin.ts        # پنل مدیریت
├── data/                   # سفارش‌ها، تیکت‌ها، جلسه‌ها، خروجی CSV
└── .env
```

## داده‌ها

| فایل | محتوا |
| --- | --- |
| `data/orders.json` | سفارش‌ها |
| `data/tickets.json` | تیکت‌های پشتیبانی |
| `data/admins.json` | مدیران ثبت‌شده |
| `data/settings.json` | تنظیمات مثل کانال |
| `data/sessions.json` | جلسهٔ کاربران |
| `data/exports/` | خروجی‌های CSV |

برای بکاپ کافی است پوشهٔ `data` را کپی کنید. با `DATA_DIR` می‌توانید مسیر را عوض کنید.

## اجرا روی سرور (۲۴/۷)

برای اینکه ربات بدون سیستم شخصی و بدون VPN همیشه روشن بماند، آن را روی یک سرور
خارج از ایران اجرا کنید. راهنمای کامل: [`DEPLOY.md`](./DEPLOY.md)

- Render (Blueprint آماده): [`RENDER.md`](./RENDER.md) — `render.yaml`
- VPS اوبونتو: `deploy/setup-vps.sh`
- Docker: `docker-compose.yml`

خلاصهٔ VPS اوبونتو:

```bash
bash /opt/veltrix-bot/deploy/setup-vps.sh   # نصب Node، سرویس systemd و ری‌استارت خودکار
systemctl status veltrix-bot
journalctl -u veltrix-bot -f
```

یا با Docker:

```bash
docker compose up -d --build
docker compose logs -f
```

> برای اعلان در کانال، ربات باید **ادمین کانال** باشد و `TELEGRAM_CHANNEL_ID` درست
> تنظیم شده باشد؛ در غیر این صورت فقط مدیران اعلان می‌گیرند.
> برای بررسی سریع عضویت اجباری، در ربات `/gate` را بزنید.

## نکات

- اگر `api.telegram.org` روی سرور مسدود است، `TELEGRAM_API_PROXY` را تنظیم کنید.
- توکن ربات را در گیت یا پیام‌رسان عمومی قرار ندهید.
